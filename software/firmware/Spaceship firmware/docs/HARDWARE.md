# Аппаратная платформа часов

Рабочая аппаратная конфигурация определяется актуальными `kicad project/8080clock.kicad_sch`, `CPU.kicad_sch`, `power.kicad_sch` и `8080clock.kicad_pcb`. Netlist и PDF схемы обновлены из этих исходников при подготовке среды 12 октября 2026 года.

## Процессор и память

| Узел | Конфигурация |
| --- | --- |
| U12 | Intel 8080 или КР580ВМ80 |
| U5 и Y1 | 8224 / КР580ГФ24 и кварц 32 МГц |
| Частота CPU | Номинально 32 МГц / 9 ≈ 3,555556 МГц; CRT и эмулятор используют 3 555 555 Гц |
| U6 | 8238 / КР580ВК38 |
| U8 | 27C256 / КР573РФ8, ROM 0000h–7FFFh, 32 КБ |
| U7 | CY62256L-70PC, RAM 8000h–FFFFh, 32 КБ |
| Стек | Начальный SP = FE00h, рост вниз |
| Старт программы | Адрес 0000h; DATA распаковывается из ROM в RAM |

Адресная разводка прямая: A12 процессора соединена с A12 памяти, A14 — с A14. В проекте используется только обычный линейный ROM.

## Дисплей и порты

Дисплей 480×320, цвет RGB565, 8-битная параллельная шина. Драйвер прошивки использует команды семейства ILI9486; соответствующее имя есть и в библиотеке проекта. Конкретную маркировку установленного модуля следует сверять с платой при изменении инициализации LCD.

| Адрес порта | Назначение |
| --- | --- |
| 00h | 8255, порт A |
| 01h | 8255, порт B; PB0 — 1-Wire |
| 02h | 8255, порт C; PC0 — SDA, PC4 — SCL, PC1–PC3 — кнопки |
| 03h | Регистр управления 8255 |
| 10h | Команды LCD |
| 11h | Данные LCD, старший и младший байт RGB565 последовательно |
| 30h–36h | Только виртуальный RTC комплектного эмулятора |

Декодирование использует A4 и младшие адресные линии; другие значения портов могут быть аппаратными зеркалами. Используйте канонические адреса из таблицы.

Полный буфер RGB565 потребовал бы 307 200 байт, что значительно больше RAM. Рисовать нужно прямо в память дисплея, обновляя небольшие области, линии и полосы. Исходная развёрнутая заливка тратит около 36 тактов на пиксель: одна передача полного экрана занимает примерно 1,56 секунды без дополнительной логики. Обещать полноэкранную анимацию в десятки кадров в секунду на этой шине нельзя.

## RTC и датчики

- U11 PCF8563P с кварцем 32,768 кГц подключён по программной I²C через 8255.
- Разъём J9 BME280: питание +5MAIN, GND, SCL, SDA. Предполагается совместимый модуль; название разъёма само по себе не подтверждает наличие преобразователя уровней на датчике.
- J7 — двухконтактное подключение 1-Wire и GND; прошивка рассчитана на DS18B20. При изменении задержек учитывать фактическое питание датчика и требования преобразования температуры.
- Для обслуживания часов использовать опрос RTC и кооперативное выполнение небольших шагов. Не предполагать наличие отдельного аппаратного тика.

## Кнопки и зуммер

SW1, SW2, SW3 замыкают PC1, PC2, PC3 на землю и имеют подтяжки. Нажатие — нулевой бит. В комплектном эмуляторе им соответствуют клавиши 1, 2, 3; Esc закрывает окно. SW4 — аппаратный сброс.

LS1, AI-1223-TWT-5V-R, связан с выходом **INTE** процессора через два инвертора 74LS04. Это отдельная возможность для новых прошивок: состояние INTE меняется инструкциями `EI` и `DI`. В исходной прошивке звуковые события не реализованы; при старте выполняется `DI`, а `EI` в CRT закомментирован.

Перед реализацией звука проверить тип установленного излучателя и активный уровень. Нельзя заранее считать его полноценным программируемым музыкальным каналом. Эмулятор звук не воспроизводит.

CPU INT и HOLD подключены к земле. Выходы INT и CLKOUT RTC не подключены. Следовательно, `EI` не создаёт периодических прерываний; ожидание через `HLT` остановит штатную работу до сброса. Использование INTE для звука учитывать отдельно от прерываний.

## Отсутствующие возможности

Контакты SD на разъёме дисплея не подключены. В этой конфигурации нет доступной SD-карты, сети, внешнего кадрового буфера или выделенной памяти сохранений. Настройки нового интерфейса можно держать в RAM или задавать при сборке; сохранение после отключения питания требует отдельного обоснования по реальной схеме.
